# Typava launch preview

Situs publik Typava: https://fiqhrodeden.github.io/typava-site/

HTML/CSS statis tanpa dependency atau build step. Jalankan lokal dengan `python3 -m http.server 4173` lalu buka http://localhost:4173.

## Publikasi

GitHub Pages melayani root branch `main`. Repo ini juga menjadi kanal feedback dan distribusi installer publik; source aplikasi berada di repo privat terpisah.

Installer belum tersedia. Setelah signing/notarization selesai, buat GitHub Release dan hubungkan CTA ke aset DMG terverifikasi. Jangan mengganti status menjadi tersedia sebelum URL unduhan publik berfungsi.

Demo di halaman adalah ilustrasi, bukan layanan terjemahan. Situs tidak memuat analytics, pelacak, font eksternal, atau form pengumpul data.
